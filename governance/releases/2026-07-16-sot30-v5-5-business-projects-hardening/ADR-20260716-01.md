# ADR-20260716-01 · ChatGPT Business Projects Runtime Envelope

Status: accepted
Owner: Семён Габран

## Context
SoT30 v5.4.1 contained routing, surface boundaries and evidence rules, but needed an explicit ChatGPT Business Projects contract.

## Decision
- Project is a context/workflow container, not an executor.
- project-only memory is required for isolated LIVE-PROJECT-PASS.
- 00-29 remains the flat Knowledge upload set.
- canonical routing is not a claim about OpenAI retrieval internals.
- connected != enabled != authorized != invoked != succeeded != verified.
- Project Instructions use one canonical paste artifact.
- Supabase memory writes require evidence and read-back.

## Scope
Knowledge: 00,02,20,22,23,28,29.
No runtime code, Supabase schema, RLS, Edge Function or privileged gateway changes.

## QA
T77-T85 plus manifest/hash/secret/ZIP checks.

## Rollback
Restore affected v5.4.1 files and regenerate manifests.
