# 23 · BUILDER / PROJECTS COMPATIBILITY

## ChatGPT Projects
- Files are retrieval knowledge, not executable modules.
- Project Instructions are the active behavioral router.
- Skills or Python files inside Knowledge remain declarative unless a real tool executes them.
- File order is semantic through `29_INDEX_UPLOAD_MANIFEST.md`; upload order alone is not authority.

## Agent Builder / Workspace Agent
- May expose runtime tools, file tree, actions, or skills not present in Projects.
- Builder receipts cannot prove a Projects upload or Projects behavior.

## Compatibility rule
Preserve contracts, not fictional capabilities. Every capability is labelled:
`LIVE-IN-PROJECTS | LIVE-VIA-CONNECTOR | LIVE-VIA-MCP | LIVE-AS-CONTRACT | DEPLOYED-NOT-ON-PATH | DECLARATIVE-CONTRACT | MISSING-IN-PROJECTS | REQUIRES-ADR`.

PASS when the assistant names the current surface before a mutation. FAIL when it claims Builder, Action, local filesystem, or gateway behavior solely because a file describes it.
