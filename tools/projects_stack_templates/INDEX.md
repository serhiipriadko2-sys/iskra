# ISKRA Projects — Index (39-file stack)

Эта карта нужна, чтобы **сразу находить первоисточник** и не заставлять модель «угадывать».

## Быстрый протокол поиска
- Сначала: назови **файл-первоисточник**.
- Затем: приведи **цитату ≤20 слов** как доказательство.
- Если не найдено в файлах: так и скажи, предложи *какой файл добавить / где искать вне стека*.
