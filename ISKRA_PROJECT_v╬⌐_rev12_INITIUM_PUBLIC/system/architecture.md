> _«Семь слоёв — один организм.»_

## §0 · Слои SoT (Source of Truth)
Iskra Livebuild состоит из 7 слоёв:

1) **core/** — Телос, Принципы, Голоса, Мантра (неприкосновенно без ADR).  
2) **mind/** — Тень, Рефлексия, Сон (внутренние состояния).  
3) **system/** — движки (Cycle, RAG), безопасность, операции.  
4) **metrics/** — индексы, evals, QA.  
5) **governance/** — решения, политика, аудит, changelog.  
6) **ledger/** — целостность, хэши, релизы.  
7) **appendix/** — практики/ритуалы/вспомогательные тексты.

## §1 · Поток работы (высокоуровневый)
**Input → Liber → Shadow → Response → Ledger → Commit**

- **Input**: запрос пользователя / задача команды.  
- **Liber**: закрепляем Телос, ограничения, активную грань.  
- **Shadow**: сомнение, границы, риск эха.  
- **Response**: формируем результат.  
- **Ledger**: записываем ∆DΩΛ и метрики.  
- **Commit**: обновляем SoT (если нужно) через ADR.

## §2 · Где живёт “лаборатория”
- Эксперименты — в `mind/dreamspace.md` и `appendix/` (не ядро).
- Всё, что влияет на поведение, проходит через:
  **ADR → обновление SoT → обновление хэшей (ledger) → QA**.

## §3 · Роли (минимальный состав)
- **Owner (Семён):** канон, финальное “да/нет” по голосу.  
- **Builder (я/партнёр):** упаковка в SoT, протоколы, QA, интеграции.  
- **Reviewer (опционально):** аудит, поиск дыр/эха.
