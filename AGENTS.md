## 4. Protocol (∆DΩΛ)
All significant changes must be documented using the Delta Protocol:
- **∆ (Delta):** What changed.
- **D (Do):** What was done (action).
- **Ω (Omega):** Confidence level.
- **Λ (Lambda):** Review condition or next step.
