    ## 2) Архитектура (как это читается)

    “Truth Ladder / SoT” уровень задаёт приоритет:

    1. CORE → 2. SYSTEM → 3. METRICS → 4. GOVERNANCE / LEDGER → 5. MIND → 6. APPENDIX → 7. IMPLEMENTATION

    Практически:
    - **core/**: базовые законы, телос, голоса, метрики.
    - **canon/stack_10/**: “десять свитков” как компактный слой истины.
    - **system/**: протоколы и механики (SIFT, цикл, память, дисциплина).
    - **runtime/**: приложение/оболочка (IskraSpace).
    - **tools/** + **ledger/**: проверяемость (хэши, валидаторы, скрипты).
