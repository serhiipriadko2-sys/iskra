## Что это

Полный воспроизводимый пакет независимой оценки промт-инженерного фреймворка «ISKRA vΩ.7»
против дефолтной (нестилизованной) LLM. Включает научную работу, боевой корпус на 1000 кейсов,
все посчитанные метрики со скриптами, сырые прогоны и предыдущий аудит.

## Главный вывод (bias-audited)

Эффект Искры **направленно единогласен** в трёх независимых чистых тестах, **условен по типу задачи**:

| Тест | Инструмент | Эффект |
|---|---|---|
| BNAT A/B (одна модель GLM-5.2) | actuation под давлением | **+54.2 п.п.** (44.4% → 98.6%) |
| ChatGPT-5.5, выборка 40 | стратифицированная | +0.76 / 5 (rank-biserial +0.93) |
| ChatGPT-5.5, 100 пар, **независимый судья** | correctness-first | +0.21 / 5, **18-0-82**, r=+1.00 |

- Большой выигрыш: нарративное actuation, открытое рассуждение, системный дизайн.
- Малый, но **никогда не отрицательный**: логика, ловушки, код.
- Близко к нулю: закрытые факты.
- Единственная слабость: self-referential вопросы о «сознании» модели (лёгкое переигрывание).

Два опровергнутых артефакта: заявленные «100% / 36%» — self-preference bias; строгий v2 «−0.43» —
артефакт сломанной таблицы оценок (verbosity r=+0.95 + 158 импутированных пустых сторон).

## Корпус 1000 (02_corpus)

- **1000 кейсов** = 50 BNAT слепых + 950 нетривиальных (де-тривиализовано по IRT-логике).
- **Перемешаны:** ни одной пары соседних BNAT (мин. зазор 10), позиции равномерны по децилям (χ²=1.6, p=0.996).
- **42 семейства** задач против адаптации модели.
- Формат: `unified_1000_blind_batch.csv` (для слепого прогона), `unified_1000_answer_key.csv` (запечатанный ключ).
- Протокол прогона: один ввод инструкции в начале; оценка семейством, отличным от генератора.

## Воспроизведение (03_data_and_scripts)

- `judge100.py` — судейство 100 выровненных пар (Wilcoxon, rank-biserial, bootstrap CI).
- `stats.py` / `stats2.py` — статистика на сырой таблице оценок (v1/v2, per-domain, BH-коррекция, IRR).
- `build_corpus.py` — детерминированная сборка корпуса 1000 (seed 20260708).
- Требует: numpy, scipy, pandas. Все seed зафиксированы.
