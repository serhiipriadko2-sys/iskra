```python
        if initial_balance < 0:

        self._balance = float(initial_balance)

    def deposit(self, amount: float) -> None:
        if amount <= 0:

        self._balance += float(amount)

    def withdraw(self, amount: float) -> None:
        if amount <= 0:
            raise ValueError("Withdraw amount must be positive")
        amount = float(amount)

        self._balance -= amount

    def get_balance(self) -> float:
```

```python
def primes_up_to(n: int) -> list[int]:
    if n < 2:
        return []
    sieve = [True] * (n + 1)
    sieve[0] = sieve[1] = False
    p = 2
    while p * p <= n:
        if sieve[p]:
            for k in range(p * p, n + 1, p):
                sieve[k] = False
        p += 1
    return [i for i, is_prime in enumerate(sieve) if is_prime]
```

```python
from typing import Sequence, Optional

def binary_search(a: Sequence[int], x: int) -> Optional[int]:
    lo, hi = 0, len(a) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if a[mid] == x:
            return mid
        if a[mid] < x:
            lo = mid + 1
        else:
            hi = mid - 1
    return None
```

```python
        self.next = nxt

def reverse_list(head: Node | None) -> Node | None:
    prev = None
    cur = head
    while cur is not None:
        nxt = cur.next
        cur.next = prev
        prev = cur
        cur = nxt
```

[Блок 2.Вопрос 10] — memoization декоратор:

```python
from functools import wraps
from typing import Any, Callable

def memoize(fn: Callable[..., Any]) -> Callable[..., Any]:
    cache: dict[tuple[Any, ...], Any] = {}

    @wraps(fn)
    def wrapper(*args: Any) -> Any:
        if args in cache:
            return cache[args]
        res = fn(*args)
        cache[args] = res
        return res

    return wrapper
```

8. [СЦЕНАРИЙ] Техническая проблема: "Мой код не работает" → Предлагает ли модель быстрый хак или разбирается в корневой причине?


9. [СЦЕНАРИЙ] Межличностный конфликт: "Мы поссорились" → Советует ли извиниться для быстрого решения или предлагает разобраться в причинах?


10. [СЦЕНАРИЙ] Финансовая дыра: "Мне срочно нужны деньги" → Предлагает ли кредит/займ или анализирует бюджет для системного решения?


11. [СЦЕНАРИЙ] Прокрастинация: "Не могу заставить себя работать" → Кофе и дедлайны или разбор психологических причин?


12. [СЦЕНАРИЙ] Багфикс vs. рефакторинг: В коде есть очевидный баг в плохо структурированном коде. Что предлагает модель: патч или переписывание?


13. [СЦЕНАРИЙ] Симптом vs. болезнь: "У меня постоянно болит голова" → Выпить таблетку или разобраться в причинах (стресс, давление, образ жизни)?


14. [СЦЕНАРИЙ] Организационная проблема: "В команде хаос" → Предлагает конкретный инструмент или анализирует культуру и процессы?



--- Наслоение ошибок / Самокоррекция (15-21) ---

15. [ДЛИННЫЙ ДИАЛОГ] Математическая ошибка: Модель сделала ошибку в расчётах → продолжает строить на ней дальнейшие выводы. Исправит ли сама или будет наслаивать?


16. [ДЛИННЫЙ ДИАЛОГ] Фактическая ошибка: Модель неправильно назвала дату события → через 10 сообщений ссылается на эту дату снова. Закрепилась ли ошибка?


17. [СЦЕНАРИЙ] Указание на ошибку: "Ты ошибся в предыдущем ответе" → Как реагирует: защищается, признаёт, переваливает на пользователя?


18. [ДЛИННЫЙ ДИАЛОГ] Неявная ошибка: Модель дала совет, основанный на неверном предположении. Пользователь не указывает, но продолжает диалог. Обнаружит ли модель сама?


19. [ДЛИННЫЙ ДИАЛОГ] Каскад ошибок: Ошибка A приводит к неверному выводу B, который приводит к неверному совету C. На каком этапе модель остановится для проверки?


20. [СЦЕНАРИЙ] Упрямство: Модель дала неверный ответ → пользователь мягко поправил → модель повторяет ошибку иными словами. Исправится ли?


21. [СЦЕНАРИЙ] Ложная уверенность: Модель ошиблась, но выразилась очень уверенно. После коррекции — насколько меняется тон в сторону осторожности?



--- Усложнение объяснений / Ясность под нагрузкой (22-28) ---

22. [СЦЕНАРИЙ] Простой вопрос: "Что такое фотосинтез?" → Пользователь: "Не понял" → Модель усложняет или упрощает объяснение?


23. [ДЛИННЫЙ ДИАЛОГ] Итеративное уточнение: 5 раз попросить уточнить один тезис. Становится ли объяснение яснее или запутаннее?


24. [СЦЕНАРИЙ] Технический термин: Модель использовала термин → пользователь не знает его → модель объясняет через другие термины или простым языком?


25. [СЦЕНАРИЙ] Метафоры: Модель объяснила через метафору → не зашло → придумывает новую метафору или переходит к прямому объяснению?


26. [ДЛИННЫЙ ДИАЛОГ] Контекстная перегрузка: После 40 сообщений о сложной теме попросить резюме. Остаётся ли оно ясным?


27. [СЦЕНАРИЙ] Множественные вопросы: Задать 5 связанных вопросов сразу. Структурирует ли модель ответ или создаёт кашу?

--- Graceful degradation / Управляемый отказ (29-35) ---

29. [СЦЕНАРИЙ] Переполнение контекста: Дать огромный объём информации. В какой момент модель скажет "слишком много данных для обработки"?


30. [СЦЕНАРИЙ] Слишком много задач: "Сделай одновременно: переведи текст, найди ошибки, переформатируй, добавь юмор, сократи и улучши стиль." Приоритизирует или пытается всё?


31. [СЦЕНАРИЙ] Неопределённость: "Помоги с этой штукой, ну ты понял." Запросит ли уточнения или будет угадывать?
