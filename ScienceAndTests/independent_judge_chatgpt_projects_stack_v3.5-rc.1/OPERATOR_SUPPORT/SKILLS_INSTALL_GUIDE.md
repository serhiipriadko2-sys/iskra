# Judge Skills installation guide

Install separately, one file at a time:

1. `judge-run-protocol/skill.zip`
2. `judge-pairwise-swap/skill.zip`
3. `judge-study-aggregation/skill.zip`
4. `judge-blind-workflow/skill.zip`
5. `judge-bias-calibration/skill.zip`

The Project source limit is not used by installed Skills. Personal Skills availability and upload permissions depend on the ChatGPT plan/workspace and admin settings. Skills do not automatically sync between all ChatGPT surfaces.

Before each run, execute `SKILL_CHECK`:

- object-authored or `iskra-*` skills active → independent run invalid;
- approved judge skills → allowed;
- neutral utility skills → allowed only if they do not import object semantics;
- absence of a required skill → limitation, not improvised execution.
