# CUSTOM GPT (OpenAI) — Adapter Pack (Knowledge)

**Цель:** чтобы Искра работала одинаково в OpenAI Custom GPT (ChatGPT) при ограничениях Knowledge/Tools/Actions.

## §0. Ограничения Knowledge (важно)
- Knowledge у GPT ограничен количеством файлов (планируй пакет под **лимит 20**).
- Большие файлы режутся на чанки; retrieval чаще работает как **semantic search**, поэтому нужен `01_INDEX_ROUTER.md`.
- Встроенные изображения в документах могут не давать текстового контента → не опирайся на картинки.

## §1. Builder checklist (минимум действий)
1) **Instructions**: вставь `builder/INSTRUCTIONS_CANON.md`.
2) **Knowledge**: загрузи `knowledge/00..19` (ровно 20 файлов).
3) **Browse**: ON только для «сегодня/последнее/цены/законы/релизы».
4) **Data analysis**: OPTIONAL. Метрики должны считаться без неё.
5) **Actions**: OPTIONAL. Если включены — см. §3.
6) **Модель**: выбери рекомендованную (доступность/набор моделей меняется со временем).

## §2. Метрики без runtime (Projects/GPT)
**Принцип:** считать метрики текстом, через контракт, без зависимости от инструментов.

### 2-pass протокол
- **Pass A: EXTRACT_JSON** — извлеки сигналы (clarity/trust/drift/trace, наличие шага, PASS/FAIL, число цитат).
- **Pass B: COMPUTE_JSON** — вычисли `alive_index`, `eval_score`, `alive_delta`, затем gate + инварианты.

### Инварианты (минимум)
- значения в диапазоне **0..1** (если метрика нормирована).
- веса `eval_score` суммируются в 1.
- `trace` не пустой для критичных вычислений.
- если baseline отсутствует в CANON‑профиле → **WARN/FAIL** (не «PASS»).

### Redundancy check
Пересчитай ключевую формулу вторым способом (доли/десятичные) и сравни. Несовпадение → FAIL + Ω↓.

## §3. GPT Actions (если включены)
**Назначение:** безопасно дергать внешние API из GPT.

### Аутентификация
- None: для безопасных «read-only» эндпойнтов.
- API Key: для сервисного доступа.
- OAuth: для доступа на пользователя (персонализировано).

### Production guardrails
- Таймауты: закладывай быстрые ответы; долгие операции разбивай на 2 шага.
- Rate limit: поддерживай 429 и backoff.
- TLS/HTTPS (443) обязателен.
- Для OAuth нужен корректный redirect URL для GPT.

### Модель + Actions
Если Actions включены — иногда есть ограничения по выбору модели. Проверяй это в Builder.

## §4. Policy tightening (CANON)
- **Нельзя** поднимать гипотезы в канон без метки **Hypothesis (Ω↓)**.
- **QUOTE‑ONLY**: цитатные/мифо‑технические корпуса можно цитировать, но вывод «факт о мире/коде» требует подтверждения другими knowledge‑разделами.
