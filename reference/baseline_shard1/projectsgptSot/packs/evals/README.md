# EvalsPack (SoT40)

Цель: превратить спор о качестве в измеримый прогон.

Состав:
- `tools/evals_offline.py` — оффлайн-харнесс (без API) для быстрых регрессий.
- `evals/cases/` — набор "golden" ответов/примеров.
- `evals/_out/dashboard.json` — отчёт (генерируется).

Принцип: **prompts as code**.
- "Код" = эталонные входы/выходы + проверяемые правила.
- CI должен падать, если эталон нарушен.
